# Inventory Management System

A beginner-friendly inventory dashboard built with HTML, CSS and JavaScript.

## Features
- Add products with a unique product ID, price and quantity
- Search products by name or ID
- View total products, total stock units and low-stock count
- Stock status labels: In stock, Low stock and Out of stock
- Delete products
- Save data in the browser using localStorage

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
5. Open the published Pages URL.

Note: This is a front-end demo. Data is stored in the browser where it is entered; it is not shared between different devices or users.
